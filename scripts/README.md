# Automation layer

Recommended pipeline:

1. Discover topic ideas.
2. Score them by search intent and usefulness.
3. Generate a draft.
4. Run quality checks: duplication, broken links, factual claims, prohibited claims.
5. Generate localized versions.
6. Publish only content that passes checks.
7. Update sitemap.
8. Track traffic and prioritize winning topics.

The starter intentionally does not hard-code a paid AI API key. That keeps the initial project at $0.
