# Deploy AI PLADUOM for free with GitHub Pages

1. Create a free GitHub account.
2. Create a new public repository, for example `ai-nova`.
3. Upload all files from this folder to the repository root.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **GitHub Actions**.
7. The included workflow will deploy the site automatically after the first push.
8. GitHub will provide a free `github.io` address.

## Before publishing
- Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` in `sitemap.xml` with the real GitHub Pages address.
- If you later buy a domain, put the domain in `CNAME` and configure DNS at the domain registrar.
- Add analytics and a newsletter only after selecting providers.
- Do not publish copied or low-quality mass-generated content.

## What this version is
A real static website that can be publicly deployed for free. It is not yet a full CMS; the next production layer is the content/admin/automation backend.
