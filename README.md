# AI PLADUOM — Zero-Budget Professional Content Platform

A mobile-first, multilingual static publication starter with English as the default interface.

## Included
- Responsive professional UI
- English-first interface
- Automatic browser-language detection + manual language switch
- Arabic, French and Spanish UI translations
- Search-ready article grid
- Dark mode
- SEO basics: title, description, canonical placeholder, robots and sitemap
- PWA manifest
- Clear places for ads/Affiliate/newsletter integrations
- Content data file for future automation

## Zero-dollar deployment
A static version can be hosted on a free static-hosting provider. No paid server is required for the starter.

## Automation architecture
The `scripts/` folder is intentionally separated so a free/local content-generation workflow can be added without tying the site to a paid API.

## Important
Do not auto-publish low-quality or copied material. Review factual claims, licensing, affiliate disclosures and platform rules before publishing at scale.
